### Windows

Run the installer. Dangle is not code-signed yet, so Windows may show
"Windows protected your PC" the first time: choose **More info**, then **Run anyway**.
Dangle lives in the tray next to the clock and keeps itself up to date.

### Android

Android 8.0 or later. Open the APK to install it (your phone may ask you to allow installs
from your browser or file manager), then let Dangle display over other apps.

## Privacy

No analytics, no account, no tracking. The only thing Dangle asks the internet is whether
there is an update, from this page's releases.
